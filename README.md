# shipdesign — Проектирование судов: от задания к облику корабля

Статический учебный сайт по теории проектирования судов (ТПС, методика
СПбГМТУ): обратная задача теории корабля — от грузоподъёмности, скорости и
дальности к водоизмещению, главным размерениям и мощности. Живые расчёты в
браузере (ванильный JS, чертежи и графики SVG, без сборки).

**Прод:** https://shadeswd.duckdns.org/shipdesign/

## Содержание
- `site/` — сам сайт (чистые HTML/CSS/JS, без сборки)
  - `index.html` — обзор курса, спираль проектирования
  - `theory.html` + `t-basics.html` / `t-stages.html` / `t-load.html` /
    `t-power.html` — четыре главы конспекта: предмет ТПС и уравнения связи,
    этапы и стадии по ГОСТ, нагрузка масс (Арнотт, Ногид, постатейный метод
    Бубнова), СЭУ и судовые запасы
  - `solver.html` — определение главных элементов судна по трём судам-аналогам:
    измерители μ, c, L/B, адмиралтейский коэффициент → водоизмещение,
    размерения и мощность; уравнение нагрузки с запасами и дедвейтом
  - `arrangement.html` — эскиз общего расположения: шпация, переборки, машинное
    отделение, двойное дно/борт, трюмы, бак, ют — с живым чертежом
  - `hullform.html` — теоретический чертёж: строевая по Хоггу с вставкой по
    Линдбладу, грузовая ватерлиния, мидель-шпангоут — с самопроверкой площадей
  - `checks.html` — проверочные расчёты: вместимость, таблицы нагрузки в грузу
    и в балласте, посадка и начальная остойчивость
  - `floodcalc.html` — непотопляемость: предельная длина отсека
  - `sources.html` — источники (лекции СПбГМТУ, методички
    Букшева—Овчинникова—Рюмина; Ашик, Ногид, Бронников)
  - `assets/` — `style.css`, общий `site.js`, движки страниц
    (`design.js`, `arrange.js`, `hull.js`, `checks.js`, `flood.js`,
    `shipdraw.js`)
- `deploy/` — docker-compose (nginx:alpine, `127.0.0.1:8068`) + конфиг nginx
- `tests/` — тесты целостности сайта (pytest)

## Стек
Статика: HTML + CSS + ванильный JS, чертежи и графики рисуются прямо в
странице (SVG). Раздача — nginx в Docker с чистыми URL
(`try_files $uri $uri.html $uri/`).

## Запуск локально
```bash
cd deploy && docker compose up -d   # проект называется shipdesign (name: обязателен!)
```
Сайт поднимется на `127.0.0.1:8068`. Наружу отдаётся через host-nginx:
`location /shipdesign/`.

## Тесты
```bash
pip install pytest --break-system-packages -q
python3 -m pytest tests/ -q
```
Тест-кит параметризуется по файлам: для каждой HTML-страницы проверяет разбор,
отсутствие дублей `id` и целостность локальных ссылок/ассетов (с учётом
clean-URL nginx), для каждого JS — синтаксис через `node --check`.
